# 📚 书源工坊 · BookSource Studio

> 零基础也能做"阅读"App 书源的可视化工具。
> 不用懂代码——打开网页，**照着提示点几下**，书源就做好了。

纯前端单文件应用，无依赖、无后端、不收集任何数据。手机浏览器直接打开就能用。

---

## 这是什么

[阅读](https://github.com/gedoor/legado)（Legado / 开源阅读 3.0）是一款流行的开源小说阅读器，它通过「书源」决定去哪个网站搜书、怎么找章节和正文。官方的规则语法对新手并不友好：要理解 CSS 选择器、`@text`、`{{key}}` 这些概念。

**书源工坊把这件事变成了"看图点选"：**

```
传统方式                          书源工坊
─────────────                    ─────────────
研究目标网站 HTML 结构            ① 粘贴网站首页
手写 CSS 选择器                   ② 粘贴一次搜索结果页的网址
反复试错、导入 App 验证            ③ 对着网页点：这块是书、这是书名、这是封面…
失败后逐条排查                    ④ 一键测试：搜书 → 详情 → 目录 → 正文 全链路
                                 ⑤ 导出 JSON，导入 App
```

## 功能特性

- **🪄 七步向导**：每一步只有一句话说明 + 一个动作，照着做就行
- **👆 可视化点选**：把目标网页原样打开（iframe 渲染），你点哪里，工具就自动生成哪里的规则；点书名会**顺带把详情链接也填好**
- **🧠 智能识别**：点中"一本书"或"一个章节"时自动猜出整个列表（命中几个、对不对，一目了然）；点正文段落会自动上提到整个正文容器
- **🔍 全链路测试**：真实联网跑一遍 搜索 → 详情 → 目录 → 正文，每步显示抓到的内容和字数，失败时给出人话提示和排查方向
- **🎯 规则微调页**：向导点选的结果自动落到这里，懂行的可以手工打磨，附语法速查表
- **📦 一键导出**：生成标准 Legado bookSource JSON，复制即可在阅读 App 里「从剪贴板导入」，也可下载 .json 或导出多书源合集
- **📥 导入已有书源**：粘贴/上传 JSON 反向解析，在可视化界面里继续修改
- **💾 本地书源库**：多书源草稿管理，自动保存（localStorage），关掉浏览器不丢
- **🌐 编码自适应**：自动识别 UTF-8 / GBK / Big5，老站不乱码
- **📱 手机优先**：单文件、无框架、暗色主题，手机浏览器即开即用

## 快速开始

### 方式一：直接打开

把 `index.html` 传到手机（微信文件传输助手 / 网盘都行），用浏览器打开；或部署到任意静态托管（GitHub Pages / Cloudflare Pages）后访问。

### 方式二：GitHub Pages（推荐）

1. Fork 或上传本仓库
2. 仓库 Settings → Pages → Branch 选 `main` / root → Save
3. 几十秒后访问 `https://<你的用户名>.github.io/<仓库名>/`

## 七步向导怎么做

| 步骤 | 你要做的 | 说明 |
|------|----------|------|
| 1 网站 | 粘贴小说站首页网址 | 名字随便起 |
| 2 搜书 | 在网站里搜一本书，把**结果页网址**贴回来 | 工具自动把关键词替换成 `{{key}}` |
| 3 搜索页 | 打开网页后点 4 下：书的整块 → 书名 → 书名/封面（取链接）→ 作者 | 点错可重试 |
| 4 详情 | 工具自动打开第一本书，点书名 / 作者 / 封面 | 可跳过 |
| 5 目录 | 随便点一个章节 | 工具自动认出整份目录 |
| 6 正文 | 点一下正文文字 | 关键规则，点准就能看 |
| 7 完成 | 跑测试 → 导出 | 全程约 10 秒 |

## 网络说明（重要）

浏览器有同源策略，网页版工具必须通过**代理**才能抓取目标网站。工具内置了几个公共免费代理并自动轮换，但公共代理**经常被限速**，能不能用全看运气。三个解决途径（按推荐程度）：

### ① 自建代理（推荐，3 分钟，永久稳定）

利用 Cloudflare Workers 的免费额度（10 万次请求/天）：

1. 注册/登录 [dash.cloudflare.com](https://dash.cloudflare.com)
2. 左侧菜单 → **Workers 和 Pages** → **创建** → 选 **"Hello World"** 模板 → 部署
3. 点 **编辑代码**，删光默认内容，把本仓库 `worker.js` 的内容**整段粘贴**进去 → **部署**
4. 复制地址栏显示的 `https://你起的名字.你的子域.workers.dev`
5. 回到书源工坊 → 向导第 1 步 → 展开「网络设置」→ 填入：
   ```
   https://你起的名字.你的子域.workers.dev/?url=
   ```

完成。此后抓取全部走你自己的代理，稳定且不限速。

### ② 手动粘贴网页（不联网也能做）

代理全挂时的保底方案，点选功能完全一样：

- **电脑**：打开目标网页 → `Ctrl+U` 看源码 → `Ctrl+A` 全选 → `Ctrl+C` 复制 → 在点选器的错误页点「手动粘贴网页」粘进去
- **文件**：把网页另存为 `.html` 后，在弹窗右上角「选文件」导入

### ③ 换网络 / 换代理

向导第 1 步「网络设置」里可一键测试所有通道的连通性；失败页也有「换个代理」按钮。

## 导入到阅读 App

1. 导出页点「复制书源」
2. 打开阅读（Legado）→ **我的** → **书源管理**
3. 右上角 **⋮** → **新建书源** → 再点 **⋮** → **从剪贴板导入**
4. 或使用「本地导入」选择下载好的 `.json` 文件（也支持导入书源合集）

## 常见问题

<details>
<summary><b>测试时"搜索书籍"失败</b></summary>

- 检查搜索地址里有没有 `{{key}}`
- 有些站点需要登录才能搜索
- 部分站点用 GBK 编码关键词，而浏览器只能按 UTF-8 编码 —— 此时直接用你粘贴过的真实结果页网址即可（工具会优先使用它）
</details>

<details>
<summary><b>目录抓到了但只有几十条</b></summary>

目录分页的站点需要填「目录下一页」规则（规则页 → 目录），阅读 App 会自动翻页。
</details>

<details>
<summary><b>正文有广告 / 站点声明</b></summary>

规则页 → 正文 → 「净化正则」，格式 `要删的正则##替换成什么`，每行一条。
</details>

<details>
<summary><b>点选时网页显示错乱</b></summary>

点选器里禁用了目标站的脚本（防止跳转），样式可能略有出入，但 DOM 结构与真实页面一致，不影响生成规则。
</details>

<details>
<summary><b>数据会丢失吗</b></summary>

书源草稿保存在浏览器 localStorage 里，清浏览器数据前请先「下载合集」备份。换设备用「导入」迁移。
</details>

## 技术说明

- **单文件**：全部 HTML/CSS/JS 在 `index.html` 内，零依赖、零构建
- **规则引擎**：浏览器内模拟 Legado 的 Jsoup 规则——`class./id./tag.` 转换、`@text/@html/@href` 属性链、`.0`/`!-1` 索引、`||` 兜底、`:regex` 截取、JSONPath；JS 规则需到 App 内验证
- **选择器生成**：从被点元素向祖先回溯，由短到长验证唯一性，产出最短可用规则；列表项字段自动生成**相对列表容器**的规则，保证导入 App 后可用
- **编码**：按响应字节流检测 `<meta charset>`，GBK/Big5 自动转码
- **隐私**：不采集、不上传；书源数据只存在你的浏览器里
